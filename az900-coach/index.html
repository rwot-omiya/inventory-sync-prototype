ABOUT THIS PROJECT

Built from one learner’s sticking points.

AZ-900 Coach is an unofficial hackathon learning tool for people who want plain-language practice with Microsoft Azure Fundamentals topics. The emphasis is on governance and management because those concepts can feel close together when you are starting out.
