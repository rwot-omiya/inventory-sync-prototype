# AZ-900 Coach build outcomes

## Working quiz experience
- Provide topic-based navigation for cloud concepts, Azure architecture and services, and Azure management and governance.
- Provide original scenario-based multiple-choice questions written for AZ-900 preparation without copying real Microsoft exam content.
- Give instant answer feedback that clearly identifies correct and incorrect choices.
- Include a beginner-friendly explanation for every answer, including why the correct option fits the scenario.

## Governance and management support
- Include focused guidance for cost management, policies, resource organization, compliance, and access control.
- Make governance and management easy to filter and revise as a focused learning area.

## AI Study Buddy prompt library
- Include reusable prompt templates for simple explanations, comparisons, examples, hints, corrections, revision summaries, and localized or African real-life examples.
- Document prompt patterns, intended use, customization, and responsible content guidelines.

## Safety and documentation
- Display a prominent disclaimer that the project is unofficial.
- Do not use Microsoft logos or reproduce real exam questions.
- Add a GitHub-ready README with setup, local development, project purpose, content safeguards, and hackathon usage.

## Delivery
- Serve a working web app on the configured Preview port.
- Verify the route manifest and app startup.
- Commit the finished app and documentation to the project repository.
